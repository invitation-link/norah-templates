## ✅ DAILY CHECKLIST (Every Single Day)

### Morning Block Tasks

#### 1. Dashboard Check (9:00-9:10) - 10 min
```
□ Check Google Analytics
  - Visitors today/yesterday
  - Top traffic sources
  - Which templates viewed most

□ Check Supabase Dashboard
  - New invitations created
  - New RSVPs submitted
  - Any errors in logs

□ Check Revenue
  - Razorpay dashboard
  - New payments
  - Failed payments (follow up)

□ Note key numbers in daily log
```

#### 2. Support & Inquiries (9:10-9:25) - 15 min
```
□ Check WhatsApp Business
  - Reply to all messages
  - Answer template questions
  - Handle complaints (priority)

□ Check Email
  - Support queries
  - Partnership inquiries
  - Payment issues

□ Check Instagram DMs
  - Customer questions
  - Collaboration requests

□ Check Facebook Comments
  - Reply to questions
  - Delete spam
```

#### 3. Social Media Engagement (9:25-9:45) - 20 min
```
□ Instagram (10 min)
  - Like 10 wedding-related posts
  - Comment on 5 potential customer posts
  - Reply to all comments on your posts
  - Check story views, reply to reactions

□ Facebook Groups (10 min)
  - Check 3 wedding planning groups
  - Answer 1-2 questions about invitations
  - DO NOT spam links (build credibility first)
```

## 🚨 EMERGENCY PROCEDURES

### If Website is Down
```
1. Check Vercel status page
2. Check Supabase status
3. Post on social media: "We're aware & fixing!"
4. Check error logs
5. Rollback last deployment if needed
6. Update customers when fixed
```

### If Payment Fails
```
1. Check Razorpay dashboard
2. Identify failed transaction
3. Contact customer via email/phone
4. Offer manual link or retry
5. Provide refund if needed
```

### If Template Broken
```
1. Identify which template
2. Rollback to previous version
3. Fix issue locally
4. Test thoroughly
5. Redeploy
6. Notify affected users
```
