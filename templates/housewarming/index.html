The short answer

What belongs on a housewarming invitation?

Include the hosts' names, the purpose of the gathering, date and time, full address, a map link, meal details and a clear RSVP request. For Griha Pravesh, also list the puja or muhurtham time when it differs from the meal.

Housewarming invitation questions

Can I include both puja and lunch timings?

Yes. Add each moment as a separate itinerary item so guests can plan clearly.

What should I write for a Griha Pravesh invitation?

Start with a blessing or warm welcome, state the ceremony, list the hosts, date, muhurtham, meal time and complete address, then close with an RSVP request.

Can I update directions after sharing?

Yes. A live invitation can be updated without changing the link guests already received.
